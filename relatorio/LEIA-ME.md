# Relatório (WebMedia)
1. No Overleaf, crie o projeto a partir do template WebMedia e envie o conteúdo desta pasta (main.tex, refs.bib, macros.tex, figuras/, tabelas/).
2. Preencha nome/e-mail (main.tex, procure TODO) e o link do GitHub.
3. Compile com pdfLaTeX + BibTeX; baixe o PDF e renomeie para 224215941.pdf.
4. Trechos marcados com `% REVISAR` são interpretações: reescreva com suas palavras.
Se refizer os experimentos: `python scripts/run_all.py` e `python scripts/gerar_tabelas_tex.py`, depois copie resultados/macros.tex para cá.
